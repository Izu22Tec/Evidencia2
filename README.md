# Sistema de Administración de Citas (Java)

Programa en **Java 11** que simula un sistema para administrar citas en un consultorio clínico.

## Instalación y configuración
- Requisitos:
  - JDK 11 instalado y configurado.
  - IntelliJ IDEA (recomendado).
- Clonar el repositorio:
  ```bash
  git clone https://github.com/Izu22Tec/Evidencia2
  cd Evidencia2

### Abrir en IntelliJ:

File → Open → seleccionar la carpeta del proyecto.

Verificar SDK: File → Project Structure… → Project SDK = Java 11.

#### Uso del programa

Ejecutar la clase Main (o la clase que tenga el método public static void main).

Funcionalidades esperadas:

Alta de doctores.

Alta de pacientes.

Crear cita con fecha y hora.

Asociar cita con doctor y paciente.

Control de acceso con usuario/contraseña (administradores).

Salida: mensajes en consola (o interfaz que hayas implementado).
